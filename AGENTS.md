# VOLPAROSSA Weather

Follow the [shared development workflow](https://github.com/VOLPAROSSA/volparossa/blob/main/docs/development/WORKFLOW.md).

For client changes, start with the relevant [Drizz.li](README.md#drizzli-web-integration)
or [Overmorrow](README.md#overmorrow-client-integration) integration. Preserve
forecast source, model run, validity window, units and attribution. Keep missing
values explicit and user locations private. Verify delivery and forecast
accuracy as separate claims.
